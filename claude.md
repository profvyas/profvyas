# profvyas - Personal Website

This repository contains the source code for [profvyas.com](https://profvyas.com), the personal website of Shubham Vyas.

## Overview

This is a static website showcasing Shubham Vyas's professional profile, projects, writing, and interests. The site is built as a Progressive Web App (PWA) with modern web standards and optimizations.

## Structure

### Main Pages

- **index.html** - Homepage with profile, interests, projects, recognition, and contact information
- **blog.html** - Blog/essays section featuring articles on technology, history, and decision-making
- **bookshelf.html** - Curated reading list and book recommendations
- **quotes.html** - Collection of notable quotes
- **coi.html** - Conversations On India - long-form interview series
- **post/** - Directory containing individual blog post HTML files

### Assets & Configuration

- **style.css** - Main stylesheet with typography and layout
- **script.js** - Client-side JavaScript (currently empty placeholder)
- **static/** - Static assets directory (images, icons, etc.)
- **manifest.json** - PWA manifest for app-like experience
- **sw.js** - Service worker for offline functionality and caching
- **robots.txt** - Search engine crawling instructions
- **sitemap.xml** - SEO sitemap for search engines
- **CNAME** - Custom domain configuration for GitHub Pages

### Documentation

- **orgchart.md** - Mermaid diagram documenting an organizational chart
- **CHANGELOG.md** - Version history and changes
- **claude.md** - This file - repository documentation

### Tooling

- **generate-icons.sh** - Script to generate PWA icons in various sizes
- **.htaccess** - Apache server configuration (if applicable)
- **.replit** - Replit IDE configuration

## Technologies Used

- **HTML5** - Semantic markup with accessibility features
- **CSS3** - Modern styling with Google Fonts (Open Sans)
- **Progressive Web App (PWA)** - Service worker, manifest, offline support
- **Google Analytics** - Traffic tracking (G-73XJCMQ45B)
- **SEO Optimizations**:
  - Open Graph meta tags
  - Twitter Card meta tags
  - Structured data (JSON-LD schema.org)
  - Canonical URLs
  - Responsive meta viewport

## Key Features

1. **Mobile-First Design** - Responsive layout that works across devices
2. **Performance Optimized**:
   - Preloading critical assets
   - DNS prefetching for external resources
   - Lazy loading images
   - Service worker caching
3. **SEO Friendly** - Comprehensive meta tags and structured data
4. **Accessibility** - Semantic HTML, ARIA labels, proper heading hierarchy
5. **PWA Support** - Can be installed as an app on mobile devices
